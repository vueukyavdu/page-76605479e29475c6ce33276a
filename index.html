挑网络接入方案，最容易犯的错是只看“快不快”。快是结果，不是条件。条件是你有多少设备、每天用多久、用来做什么。这三件事决定了你该付多少钱。

所以这一页不写形容词。下面是一张能横向读完的对比表、几段客户端设置说明，以及我们被问得最多的那些问题。看完再决定，不急。

如果你只想要一句话结论：单人日常从基础版开始，多用设备或有游戏需求看旗舰版，多人共用看团队版。

01

先读这三段

读完之后，对照表基本能自己看懂。

一流量是上限，不是目标

100GB 对刷网页和看视频的人够用一个月，对天天挂着下载的人只够一周。先看你上月实际用量，再往上选一档，别往下选。

二设备数决定档位下限

手机、电脑、平板、电视盒子各算一台。三台以内基础版就够；超过五台，别硬挤，直接看团队版。

三年付省的是耐心

年付省下一次次续费的麻烦，月付省的是试错成本。第一次用，建议先月付一个月。

03

客户端与设置

同一份配置，在不同系统上的操作路径。步骤不多，按顺序走一遍即可。

Windows

桌面端接入

适合需要长时间挂着电脑办公或游戏的场景，也是最多人用的入门方式。

  1. 安装完成后打开主界面，确认网络适配器正常。
  2. 导入服务方提供的配置，粘贴整段文本，不要手动截断。
  3. 选择节点，点击连接，等待状态变为已连接。
  4. 打开浏览器访问一个常用网站，确认走通。

安装包与配置请在购买后提供的页面获取；本页不提供直接下载地址。

macOS

轻量使用

系统权限设置比 Windows 多一步，遇到连不上先看这里。

  1. 首次启动需在系统设置中允许其运行。
  2. 导入配置后，选择“全局”或“规则”模式。
  3. 日常浏览建议用规则模式，减少不必要的转发。
  4. 连接异常时，先关闭再重新打开客户端。

不同系统版本界面略有差异，以实际安装版本为准。

iOS / Android

移动端

手机上最常见的两个问题：后台被系统杀掉、切换网络后未重连。

  1. 在移动端应用中添加配置，或扫码导入。
  2. 允许添加网络配置的权限提示。
  3. 切换 Wi-Fi 与流量后，手动检查连接状态。
  4. 多设备使用时注意同时在线台数上限。

应用来源请以官方应用商店的服务方说明为准。

路由器 / 电视盒子

整屋共用

把这套配置放到路由器上，全屋设备就不用一台台设置。

  1. 确认路由器固件支持自定义配置导入。
  2. 将配置写入并重启路由器。
  3. 用一台手机连接该 Wi-Fi 做连通测试。
  4. 把连接的设备数记下来，对照套餐上限。

此项操作门槛较高，不熟悉的建议保持单设备方式。

04

怎么开始

四步。每一步都能停下来确认，不必一次做完。

  1. 数设备

    把会用到的手机、电脑、平板、电视盒子列出来，得出总数。

  2. 看用量

    回忆上个月看视频、下载、会议一共用了多少，宁高勿低。

  3. 选档位

    对照上面的表格锁定一档；第一次用，先选月付。

  4. 配客户端

    按系统找到对应说明，导入配置，先在一台设备上跑通。

05

常见问题

按被问到的频率排列，左侧偏购买，右侧偏使用。

三档之间的核心差别是什么？

流量、同时在线设备数、线路类型、支持方式。价格差别基本跟着这四项走，所以先定设备和用量，答案自然出来。

年付一定比月付划算吗？

按数字算，年付总额约等于十个月。但前提是你确定会长期使用。第一次接触，先月付一个月，看实际是否顺手。

流量超了会怎样？

各档按每月流量额度计。具体超出后的处理方式请以购买页说明为准，本页不做承诺。选档时留出余量更稳妥。

可以中途换档吗？

档位调整规则由服务条款约定。升级通常在下一计费周期生效，具体以购买页显示为准，下单前请先确认。

设备数怎么算？

同一时间在线的设备计入。手机、电脑、平板、电视盒子各算一台。用完退出，名额就释放出来。

连不上怎么办？

按顺序排查：确认配置完整导入、切换节点、重启客户端、换一台设备测试。四步都试过仍有问题，再提工单。

为什么本页没有下载链接？

我们不在这里放置未经确认的安装包地址。客户端与配置应从购买后提供的渠道获取，避免装到来源不明的版本。

团队版适合什么样的情况？

多人共用、设备较多、需要固定对接人的场景。它有专属客户经理，沟通路径比工单更直接，费用也相应更高。

能保证速度和稳定性吗？

不能。速度受本地网络、时段、目标网站等多重因素影响。我们不在页面上写任何性能承诺，只把套餐结构讲清楚。

页面上看不到的信息去哪问？

看购买页的服务条款，或通过服务方提供的工单渠道询问。涉及计费与规则的问题，以书面说明为准。
